# ЖК «Премиум» — интерактивный 3D-макет

[Открыть опубликованный макет](https://plan-273-standard.vercel.app/premium.html)

Объёмная сцена жилого комплекса с внутренним двором и наружной аллеей. Создана на Three.js 0.180.0 по предоставленным изображениям: два связанных крыла, фасады и витрины, окна и ограждения, входы, озеленение, игровые площадки, дороги и автомобили. Материалы и текстуры создаются программно. Фасады сверены с проектными визуализациями и фотографиями строительства. Коммерция расположена только на первом этаже. На втором этаже показаны окна с простенками и подоконниками.

## Управление

- Перетаскивание мышью или жестом — вращение.
- Колесо мыши или жест двумя пальцами — приближение и отдаление.
- Двойной клик на поверхности — переход к обзору с уровня глаз.
- Escape — возврат к общему виду.

## Локальный запуск

Нужны Python 3, современный браузер с WebGL и подключение к интернету для загрузки Three.js с jsDelivr.

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/premium.html`.

## Файлы

- `premium.html` — полноэкранная страница и карта импортов.
- `premium-scene.js` — материалы, благоустройство, освещение и управление камерой.
- `premium-facade.js` — геометрия и отделка фасадов, окна, лоджии и распределение этажей.

Линейные архитектурные размеры в исходных материалах отсутствовали. Пропорции и невидимые поверхности восстановлены приблизительно; макет предназначен для визуального ознакомления.

Репозиторий содержит исходники макета. Автоматическая публикация и workflow не настроены.
