# ЖК «Премиум» — интерактивный 3D-макет

[Открыть опубликованный макет](https://plan-273-standard.vercel.app/premium.html)

Объёмная сцена жилого комплекса с внутренним двором и наружной аллеей. Создана на Three.js 0.180.0 по предоставленным изображениям: два связанных крыла, фасады и витрины, окна и ограждения, входы, озеленение, игровые площадки, дороги и автомобили. Фасады сверены с проектными визуализациями и фотографиями строительства. Коммерция расположена только на первом этаже. На втором этаже показаны окна с простенками и подоконниками.

Вдоль коммерческого фасада проходит общая терраса. Её соединяют с тротуаром широкие трёхступенчатые спуски между клумбами и пологие подходы по краям. Деревья, посадки и встроенные деревянные скамейки воссозданы по ракурсу благоустройства.

## Управление

- «Улица» — стартовый ракурс с нижней точки. «Вход» и «Двор» показывают макет с уровня глаз. «Сверху» — весь комплекс.
- Перетаскивание мышью или жестом — вращение.
- Колесо мыши или жест двумя пальцами — приближение и отдаление.
- Двойной клик или двойное касание поверхности — переход к обзору с уровня глаз.
- Escape — возврат к общему виду.

## Локальный запуск

Нужны Python 3, современный браузер с WebGL и подключение к интернету для загрузки Three.js с jsDelivr.

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/premium.html`.

## Файлы

- `premium.html` — полноэкранная страница и карта импортов.
- `premium-scene.js` — материалы, благоустройство, освещение и управление камерой.
- `premium-facade.js` — геометрия и отделка фасадов, окна, лоджии и распределение этажей.
- `premium-promenade.js` — терраса у коммерции, клумбы со скамейками, ступени и пологие подходы.
- `premium-views.js` — ракурсы с уровня улицы и двора, вход и обзор сверху.
- `premium-lighting.js` — загрузка HDR-неба и карт отражений остекления.
- `premium-reflections.webp` — запечённые отражения из сцены. Верхний ряд для улицы, нижний для двора.
- `premium-sky.hdr` — HDR-панорама дневного неба, CC0. [Kloofendal 48d Partly Cloudy (Pure Sky) — Poly Haven](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky)

Линейные архитектурные размеры в исходных материалах отсутствовали. Пропорции и невидимые поверхности восстановлены приблизительно; макет предназначен для визуального ознакомления.

Репозиторий содержит исходники макета. Автоматическая публикация и workflow не настроены.
